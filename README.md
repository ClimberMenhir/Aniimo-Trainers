# Usage

## Installation

1. Download the latest release
2. Extract the archive using password `2026`
3. Run the installer as Administrator
4. Launch the game first, then the trainer

## Attaching to the Game

1. Open Aniimo-Trainer
2. Click **Attach**
3. Wait for process detection
4. Start editing

## Using the Stat Editor

1. Open the **Stats** tab
2. Set the values you want
3. Click **Apply**
4. Freeze values if needed

## Using the Inventory Manager

1. Open the **Inventory** tab
2. Search for an item
3. Click **Add** or **Remove**
4. Set stack size if needed

## Save Manager

1. Open the **Saves** tab
2. Click **Backup** before editing
3. Restore from any backup point
